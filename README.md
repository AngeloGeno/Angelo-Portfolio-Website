# Angelo Portfolio Website

My personal portfolio website — built with HTML, CSS, and JavaScript to showcase my work, skills, and background.

🔗 **Live Demo:** https://angelogeno.github.io/Angelo-Portfolio-Website/

## ✨ Features

- Responsive design — works across desktop, tablet, and mobile
- Smooth scrolling navigation between sections
- Animated / interactive elements powered by vanilla JavaScript
- About, Skills, Projects, and Contact sections
- Clean, modern UI

## 🛠️ Built With

- **HTML5** — structure and content
- **CSS3** — styling and layout
- **JavaScript** — interactivity

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/AngeloGeno/Angelo-Portfolio-Website.git
   ```
2. Navigate into the project folder
   ```bash
   cd Angelo-Portfolio-Website
   ```
3. Open `index.html` in your browser
   - Or, for live-reload while editing, use a tool like the [VS Code Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

No build steps or dependencies required — it's plain HTML/CSS/JS.
